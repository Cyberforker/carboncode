# 既有代码分析

分析对象：`/Volumes/CopilotDisk/Codes/CarbonCode/carboncode`

## 项目技术栈

- 语言/运行时：TypeScript、ESM、Node.js `>=22`
- CLI：`commander`，入口 `src/cli/index.ts`，bin 为 `carboncode` / `ccode`
- TUI：`ink` + `react`，主组件 `src/cli/ui/App.tsx`
- LLM/Agent：DeepSeek 原生客户端 `src/client.ts`，核心循环 `src/loop.ts`
- 模型策略：围绕 `deepseek-v4-flash` / `deepseek-v4-pro`，包含 flash→pro 升级和成本控制
- Dashboard：Preact + HTM，前端在 `dashboard/`，后端在 `src/server/`
- Desktop：Tauri 2 + React + Vite，Rust 后端在 `desktop/src-tauri`
- 构建：`tsup` 构建 library / CLI / dashboard，desktop 使用 Vite/Tauri
- 测试与质量：Vitest、V8 coverage、Stryker、Biome、simple-git-hooks
- 扩展能力：MCP client/bridge、语义索引、QQ Bot、ACP、本地 session/transcript/usage

## 启动方式

### 安装后使用

```bash
npm install -g @carboncode/cli
cd path/to/project
carboncode
```

短命令：

```bash
ccode
```

临时运行：

```bash
npx @carboncode/cli
```

配置 DeepSeek Key：

```bash
export DEEPSEEK_API_KEY=sk-...
```

或通过首次运行 setup 写入：

```text
~/.carboncode/config.json
```

### 本地开发启动

```bash
npm install
npm run dev        # tsx src/cli/index.ts，默认进入 setup 或 code 模式
npm run chat       # tsx src/cli/index.ts chat
npm run build      # tsup + dashboard vendor css copy
npm run test       # vitest run
npm run lint       # biome check src tests
npm run typecheck  # tsc + dashboard typecheck
npm run verify     # build + lint + typecheck + test
```

构建后：

```bash
node dist/cli/index.js
```

### CLI 子命令

```bash
carboncode code [dir]
carboncode chat
carboncode run "task"
carboncode setup
carboncode doctor
carboncode sessions
carboncode replay <transcript>
carboncode diff <a> <b>
carboncode mcp list|search|install|browse|inspect
carboncode index
carboncode update
```

### Desktop 启动

```bash
cd desktop
npm install
npm run dev
npm run build
npm run tauri dev
```

## 核心业务模块

1. CLI 命令路由：`src/cli/index.ts`
   - 注册所有子命令，处理配置优先级、model/preset、dashboard、session、MCP 参数。
2. 交互式 TUI：`src/cli/commands/chat.tsx`、`src/cli/ui/App.tsx`
   - prompt 输入、slash 命令、session picker、plan/edit/shell 确认弹窗、MCP hub、dashboard 状态、cost/context/status 显示。
3. Agent 核心循环：`src/loop.ts`
   - Immutable Prefix、Append-only Log、Volatile Scratch、prompt cache 优化、flash→pro 成本控制、tool dispatch、session resume/heal、budget 限制。
4. DeepSeek 客户端：`src/client.ts`
   - `/chat/completions`、SSE streaming、usage/cache token 统计、balance/model list、retry、rate limit、660 秒超时策略。
5. Tool 系统：`src/tools.ts`、`src/tools/*`
   - filesystem、shell/jobs、web、memory、plan、choice、todo、skills、subagent、scaffold。
6. Code 模式：`src/cli/commands/code.tsx`、`src/code/setup.ts`
   - sandbox、文件读写/搜索、shell 审批、SEARCH/REPLACE edit block、diff preview、checkpoint/restore、`/cwd`、`/add-dir`。
7. MCP 集成：`src/mcp/`
   - stdio、SSE、streamable-http、MCP marketplace/catalog、MCP tool bridge。
8. Memory / Session / Transcript：`src/memory/`、`src/transcript/`
   - 数据在 `~/.carboncode/config.json`、`~/.carboncode/sessions/`、`~/.carboncode/memory/`、`~/.carboncode/usage.jsonl`。
9. Dashboard：`dashboard/`、`src/server/`
   - sessions/messages、plans、changes/diffs、tools、MCP、memory、usage、settings、semantic、SSE live events；默认 `127.0.0.1` + token 鉴权。
10. Desktop：`desktop/`
    - Tauri 2 + React + Vite + Rust bridge，CLI 内部命令 `carboncode desktop`。

## 当前可能存在的维护风险

1. Reasonix 遗留痕迹较多
   - `CHANGELOG.md`、docs/design、legacy `.reasonix`、`REASONIX_*`、`x-reasonix-token`、tokenizer 兼容路径等仍存在。
2. 版本号不一致
   - root `package.json` 为 `0.2.5`，desktop 为 `0.43.0`，CHANGELOG 仍记录 Reasonix `0.46.0`。
3. 单文件体积偏大
   - `src/cli/ui/App.tsx` 约 4549 行，`src/i18n/*`、`src/cli/commands/desktop.ts`、`src/loop.ts`、`src/config.ts` 都较大。
4. 多端形态增加维护面
   - CLI、Ink TUI、Dashboard、Desktop、ACP、QQ Bot、MCP marketplace、Docs site 同时存在。
5. Dashboard 前端类型约束较弱
   - `dashboard/tsconfig.json` 中 `allowJs: true`、`checkJs: false`，主体是 JS/Preact/HTM。
6. DeepSeek API / 模型 ID 强依赖外部变化
   - 模型命名、thinking、reasoning_effort、cache usage、价格字段变化会影响核心路径。
7. 手写 MCP client 有协议漂移风险
   - 选择不用官方 SDK，需持续跟进 MCP spec 演进。
8. 安全/权限边界复杂
   - shell、文件、dashboard mutation、MCP、hooks、API key、yolo/auto/review 等交叉路径多。
9. Legacy 兼容逻辑拖累简洁性
   - `.reasonix` fallback、legacy preset、legacy env/header/config 合并长期增加测试矩阵。
10. 发布/CI 覆盖存在缺口
    - 目前主要 root CI 是 Ubuntu + Windows 的 `npm run verify`；desktop/Tauri/macOS 覆盖需关注。
